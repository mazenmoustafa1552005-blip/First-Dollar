# Studio research

Applies to First Dollar (kids' mystery games, dollhouse miniatures, no-sew crochet).

## Rules
1. Start from product type and buyer intent, not a fixed platform list. Expand via category searches, competitor storefront links and "alternatives to X".
2. Every claim gets a status: `confirmed (public docs + URL)`, `conditional (account verification)`, `unsupported`, or `unknown: <exact open question>`.
3. Verify seller registration and payout separately. Egypt facts that gate everything: Stripe accounts cannot be opened in Egypt; check PayPal, Payoneer and local bank options per platform.
4. Keep evidence signals separate and labelled: `[LP]` listing price, `[LR]` listing reviews, `[SS]` cumulative shop sales, `[SC]` search counts/interest, `[EST]` third-party estimates. Never sum or convert one into another.
5. Log every query and fetched page with the date in `research/search-log.md` (platforms) or the "Search log" section of the file you edit. If a host is blocked by the network allowlist, log it as a gap: do not guess.
6. Never put the owner's name, email or store in a search query.

## Files
- `research/platforms.md`: one subsection per platform, near-misses, per-line ranking, open questions.
- `research/market-evidence.md`: comparable products per line + synthesis.
- `research/organic-acquisition.md`: social/community examples with evidence grade.
- Refresh `platforms.md` (date each change) before any account connection or publish.
